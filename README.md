# Bidcoin
🛠 주요 기술적 개선 사항 (Chunking & Tokenization)
- 기존의 단순 공백 기반 토큰화의 한계를 극복하기 위해 다음과 같은 전처리 파이프라인을 구축했습니다.

- Kiwi 형태소 분석기 도입: 한국어 특유의 조사와 어미를 정교하게 분리하여 의미 있는 명사 위주의 키워드 추출이 가능해졌습니다.

- 하이브리드 청킹 전략: 문서의 구조를 유지하면서도 검색 효율을 높이기 위해 의미 단위로 텍스트를 분할하고, 메타데이터(사업명, 공고번호)를 각 청크에 결합하여 검색 재현율(Recall)을 높였습니다.

📂 주요 파일 설명
🧠 검색 엔진 (Engines)
- rag1_engine.py: 베이스라인 모델입니다. FAISS를 이용한 **벡터 검색(Dense Retrieval)**만을 사용하여 문맥적 유사도를 바탕으로 답변을 생성합니다.

- rag1_engine_hybrid.py: 의미 검색(FAISS)과 키워드 검색(BM25)을 결합한 하이브리드 엔진입니다. Kiwi 형태소 분석기를 통해 고유명사나 숫자 등 정밀한 키워드 매칭 성능을 보완했습니다.

- rag1_engine_multiquery.py: 최첨단 Multi-Query 엔진입니다. LLM이 사용자의 모호한 질문을 4개의 전문적인 검색어로 확장하고, 각 검색 결과의 점수를 합산(RRF)하여 검색 사각지대를 완전히 제거합니다.

🤖 실행 스크립트 (Chatbot UI)
- rag2_run_chatbot_v1.py: 기본적인 하이브리드 검색 기반의 챗봇 인터페이스입니다. 대화 기록 관리 및 기본적인 RAG 답변 기능을 제공합니다.

- rag2_run_chatbot_v2.py: 멀티 쿼리 기능이 통합된 최종 진화형 챗봇입니다. 확장된 검색어 노출, 실시간 팩트체크(매칭수 및 점수 확인) 기능을 포함하여 신뢰도 높은 상담이 가능합니다.

🧪 전처리 및 파이프라인 (Data Pipeline)
- chunk1_processor.py: 원본 문서를 분석하고 Kiwi 분석기를 통해 최적의 청크로 분할하는 전처리 스크립트입니다.

- chunk2_run_pipeline.py: 전체 데이터셋에 대해 청킹 작업을 일괄 수행하고 통합 DB를 생성하는 파이프라인입니다.

- run_embedding.py: 생성된 청크들을 OpenAI의 최신 임베딩 모델을 통해 벡터화하고 FAISS 인덱스를 구축하는 역할을 합니다.
